硬性要求：
1. 工作目录就是 /opt/kaixinguor/site，技能里出现 Mac 的绝对路径（/Users/or/...）一律换成本目录。
   窗口先跑 `node scripts/coverage.mjs window --section ai`：
   - 当天文件已存在（重跑）→ 沿用它打印的 start/end，不要按当前时间重算；
   - 还没有当天文件 → 起点接上一期 windowEnd，终点用现在。
   只收发布时间落在窗口内的报道，境外来源先换算成北京时间。
2. 每条候选都要打开原文核对标题、发布时间、正文首段；403、登录墙、软 404、只有搜索摘要的一律换源或删条，不许凭标题补写。
3. 中英双稿成对产出：daily-ai/web/__DATE__.html 与 daily-ai/web/__DATE__-en.html，期号 +1，四份共用同一窗口终点。
4. 发布前自检全绿：parseIssue、node scripts/coverage.mjs check、node scripts/check-links.mjs、npm run style。
5. 发布：node scripts/publish-daily.mjs daily-ai/web/__DATE__.html --en daily-ai/web/__DATE__-en.html --push
6. 发布成功后同步到线上：/opt/kaixinguor/bin/sync-site.sh --no-build
7. 只改本版块的文件（daily-ai/、templates/、必要的 scripts/）。不要动 docs/、deploy/、其它三份日报，不要 git push --force，不要 --allow-bad-links 硬发。

任何一步失败就停下，把卡住的命令和原因写进最后一段输出，不要假装成功。
