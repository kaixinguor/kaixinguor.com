执行今天的经济日报（__DATE__，北京时间）。

工作目录 /opt/kaixinguor/site。先读 docs/每日四报统一规则.md 和 docs/每日生成任务-经济日报.md，并使用 .dsh/skills/kaixinguor-daily 技能；窗口、检索、核验、双语写作、自检全部按这两份文档执行。

硬性要求：
1. 工作目录就是 /opt/kaixinguor/site，技能里出现 Mac 的绝对路径（/Users/or/...）一律换成本目录。
   窗口先跑 `node scripts/coverage.mjs window --section economy`：当天文件已存在就沿用打印的 start/end，不存在则起点接上一期 windowEnd、终点用现在。只收窗口内的报道，境外来源先换算北京时间。
2. 每条候选都要打开原文核对标题、发布时间、正文首段；打不开就换源或删条。
3. 先看一眼今天的 AI 日报（daily-ai/web/__DATE__.html）写了什么，避免头条和角度撞车。
4. 中英双稿成对：daily-economy/web/__DATE__.html 与 __DATE__-en.html，期号 +1。
5. 自检：parseIssue、node scripts/coverage.mjs check、node scripts/check-links.mjs、npm run style。
6. 发布：node scripts/publish-economy.mjs daily-economy/web/__DATE__.html --en daily-economy/web/__DATE__-en.html
7. 发布成功后：/opt/kaixinguor/bin/sync-site.sh --no-build
8. 只改本版块的文件。不要动 docs/、deploy/、其它三份日报。**不要执行 git push / git commit**（推送由外层 run-daily.sh 重试完成），不要 --allow-bad-links 硬发。

任何一步失败就停下，把卡住的命令和原因写进最后一段输出。

网络注意：这台服务器实测访问 www.nytimes.com、www.reuters.com 会超时（12 秒无响应），选源时避开这两个域名，改用同事件的官方公告、一级源或能打开的等价媒体，不要因为打不开就凭标题补写。
