# 社交配图规则（AI 日报）

> 2026-10-30 确定。以后每次生成日报配图都按这份执行，不要再按旧习惯改回去。
> 执行脚本：`scripts/make-social.mjs`；版式：`scripts/social/template.mjs`。

## 1. 只做公众号，停做小红书

- 配图**只服务公众号「图片消息」**（贴图），不再生成小红书图。
- `xhs/` 目录、`AI-Daily-YYYY-MM-DD-xhs.zip`、1242×1656 那一套全部作废；脚本传 `--only xhs` 会直接报错。
- 原因：小红书要另起一套比例和版式，维护成本翻倍；日报的实际分发只走公众号。

## 2. 固定 5 张，没有尾页

```
01-cover      封面
02-story-1    重点 1
03-story-2    重点 2
04-story-3    重点 3
05-overview   速览（收尾）
```

- 尺寸 **1080×1440（3:4）**，画布 1242×1656 截图时缩到 1080。
- **砍掉尾页**（旧的 `06-outro`）。理由：尾页是自我介绍“一份 AI 日报正好 24 小时 + 域名”，对已经关注你的公众号读者是浪费一次滑动；小红书那种陌生流量池才需要导流页。
- 尾页原来承载的**免责声明不要丢**。固定文案与网页完全一致（网页页脚的 `<p class="disclaimer">`）：

  > 本期内容由 AI Agent 搜索、整理并总结，所有条目均链接原文；事实与数字以原文为准，仅供参考。标题与点评为编辑加工，不代表任何来源立场。

  出现两处，都是脚本自动生成：

  1. **01 封面底部**（统计条上方，一行小字）。选封面而不是速览页，是因为速览页要放 6–9 条，加字会挤掉最后一条的正文；封面的空白带是固定的，不受条数影响。
  2. **图片消息的描述正文末尾**（`公众号-图片消息.md` 里可直接复制的那一段）。

  **脚本不手写这段文字**：`make-social.mjs` 会从当天日报页面里抓 `<p class="disclaimer">` 的整段内容，**连“声明”两个字一起**（图上把它排成朱红等宽小字，和网页 `.disclaimer b` 同一套样式）。所以只要网页改了声明，图会跟着变，两边不会漂。改声明只需改网页（`ai-daily/` 源稿 + `site/daily-ai/` 成品页），然后重跑配图。

## 3. 标题：固定模板，日期是唯一变量

```
AI 日报 · 10月30日
```

规则：

- 前缀永远 `AI 日报 · `，后面跟**中文月日、不补零、不带星期**；
- **不写期号**：封面右上角已经有“第 005 期”，标题重复是浪费；
- **不用当天 headline 当标题**：每天变、动辄 30+ 字会被截断，且和封面主标题完全重复；
- 想加钩子只用固定后缀形式：`AI 日报 · 10月30日｜9 条`；
- 脚本已把它写进 `manifest.json` 的 `wechatTitle` 和 `公众号-图片消息.md`，不要手改。

## 4. 每期产物（`../ai-daily/social/YYYY-MM-DD/`）

| 文件 | 用途 |
|---|---|
| `wechat/01-cover.png … 05-overview.png` | 5 张成品图，按序拖进公众号后台 |
| `公众号-图片消息.md` | 标题 / 描述 / 逐图说明 / 发布步骤，直接复制 |
| `README.txt` | 发布顺序与本期元信息 |
| `manifest.json` | 机读元信息（含 `wechatTitle`、`files.wechat`） |
| `AI-Daily-YYYY-MM-DD-wechat.zip` | 整包发送用的 zip（`--no-zip` 可关） |

只生成在本地，不进 `site/` 仓库、不提交、不部署。

## 5. 发布时的两个注意事项（写进文案里）

1. **封面会被裁**：首图就是封面，信息流里按 1:1 / 16:9 之类的比例展示，原图 3:4，发前必须在预览里看一眼，必要时调裁剪区。
2. **不要两版都群发**：个人订阅号一天只有 1 次群发额度。图片版群发，HTML 图文版走「发表」（生成公开链接、不推送、不占群发次数）。

## 6. 为什么不是 API 自动发

个人主体订阅号不能微信认证，2025 年 7 月起发布 / 群发相关接口权限被回收（`draft/add` 也常返回 `48001`），所以图片消息只能手动发。哪天换成企业/个体户主体并认证，再走 `draft/add`（`article_type: "newspic"`）+ `freepublish/submit`，那时这份文档的“手动”部分才需要改。
