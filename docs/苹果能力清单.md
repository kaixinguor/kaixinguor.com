# 苹果能力清单

> 用途：收到一个许愿时，先翻这里——**系统自带的能不能干？**
> 不是给用户看的页面，是我自己的决策工具。三个月更新一次就够。
>
> 最后更新：2026-10-24 · 系统版本：macOS 26.6.2

---

## 怎么用

拿到一条需求，按三步走：

1. 在下面找到最接近的"想干的事"
2. 看"系统自带"那一列——够用的话，直接劝退用户，别做
3. 系统做不到、或者做得很别扭 → 再评估自己做的成本

**判据不是"系统有没有这个功能"，是"用户会不会真的去用它"。**
系统有但藏得很深、需要三步操作的功能，等于没有。

---

## 清单

| 想干的事 | 系统自带 | 够用吗 | 缺口 / 我的机会 |
|---|---|---|---|
| 把视频里说的话变成字 | 辅助功能 → **实时字幕** | ⚠️ 看得到，留不下 | **不留稿子、不能整理** → 课堂字幕 |
| 把录好的音频转成文字 | **备忘录** 里录音 → 自动转录；**语音备忘录** 也有 | ✅ 够用（事后转录） | 实时性差，长音频慢 |
| 扫描书页上的字 → 可复制 | **预览 + 实况文本** | ⚠️ 一页一页手动框 | 不能整本、没有批注和笔记 → 摘读 |
| 整本扫描 PDF 的全文搜索 | ❌ 无 | ❌ | 机会（但成本高：要建索引） |
| 会议录音 + 摘要 | **备忘录 / FaceTime** 的转录 | ⚠️ 只有苹果自家 App | 第三方会议（腾讯会议、Zoom）盖不到 |
| 截图里的字 | **⇧⌘4 + 实况文本** | ✅ 够用 | 别做 |
| 手写笔记转文字 | **备忘录**（Apple Pencil） | ✅ 够用 | 别做 |
| 网页正文摘出来 | **Safari 阅读器 + 朗读** | ✅ 够用 | 别做 |
| 定时提醒、待办 | **提醒事项** | ✅ 够用 | 别做 |
| 简单表格计算 | **Numbers** | ✅ 够用 | 别做 |
| 文件批量重命名 | **访达 + 快捷指令** | ⚠️ 要写快捷指令 | 有空间做"傻瓜版" |
| PDF 合并 / 拆分 / 压缩 | **预览** 能做合并拆分；压缩不行 | ⚠️ | 压缩有空间，合并别做 |
| 图片批量改尺寸 | **预览 / 快捷指令** | ✅ 够用 | 别做 |
| 屏幕取色 | **数码测色计**（系统自带） | ✅ 够用 | 别做 |
| 剪贴板历史 | ❌ 无 | ❌ | 机会（但已有 Raycast/Paste 等强敌） |
| 窗口分屏 | **系统自带分屏 / 台前调度** | ✅ 够用 | 别做 |
| 朗读选中文字 | **系统朗读**（右键 → 朗读） | ✅ 够用 | 别做 |

## 已知的坑

- **「实时字幕」是课堂字幕最直接的对手**，而且免费。我们的立足点必须是"留下稿子 + 整理"，不是"有字幕"。
- **Apple 每年 9 月改系统**，今年能做的明年可能自带。所以产品要卖"工作流"，不要卖"某个功能"。
- 上表按 **macOS 26** 写。iOS/iPadOS 的能力不一样，评估手机端需求时要另查。
