# 问题层 · 判准

> 这一层不加新闻，只在事实层上长出问题。
> 它不判断你答得对不对，也不记录你带走了哪一问。

## 一句话定义

**深刻的问题，是一句话就能答、但答完之后你必须改口的问题。**

三个条件缺一不可：

1. **答得出来**——能用一句话给出一个「看起来对」的答案。答不出来的是玄学，没法讨论。
2. **答完要改口**——那个答案会逼你修正一个你原本默认的前提。不改口的是知识题，只是加了个事实。
3. **改的是承重墙**——被你修正的那个前提，属于某个学科里少数几条真正撑着别的东西的结论。

第三条决定了：**深不深，不看题目大不大，看答完之后你的模型动没动。**
宏大而无法回答的问题（「AI 将如何改变社会」），比具体而能改口的问题浅得多。

## 承重墙清单（是目录，不是排班表）

金融与社会这条线上，真正承重的没有几条：

| | 承重的那条 | 它管什么 |
|---|---|---|
| 1 | 稀缺与机会成本 | 一切「划算不划算」的起点 |
| 2 | 激励与委托 | 谁付钱、谁承担后果、谁做决定 |
| 3 | 信息与信号 | 这个数字是被谁做出来给人看的 |
| 4 | 时间与贴现 | 明天的钱为什么比今天便宜 |
| 5 | 风险与不确定性 | 能算的叫风险，不能算的那部分才要命 |
| 6 | 货币与信用 | 钱是怎么被造出来的，谁在造 |
| 7 | 会计恒等式 | 一笔钱记在谁的表上，什么被藏起来了 |
| 8 | 交易成本与企业边界 | 为什么有些事在公司里做，有些事去市场上买 |
| 9 | 规模与权力 | 大到什么程度，定价权就从市场转到它手里 |
| 10 | 规则与裁量 | 约束不会消失，只会换个地方落 |

**用法是「查」，不是「轮」。** 今天的新闻落在哪面墙上，就问哪面墙。
落不上，今天就不问——**不设固定轴、不排班**。填空的冲动会训练出模板，模板会训练出假深刻。

## 四种提问形态

一条真问题通常落在其中一种上，可以叠：

- **条件问**：这条规律在什么条件下不成立？
- **反例问**：按这个逻辑应该发生 X，实际是 not-X，差在哪？
- **归属问**：这笔钱、这个决定，最后落在谁的表上，谁承担后果？
- **通约问**：这两样不一样的东西，凭什么能被放在一起比较、相加、折算？

## 两个维度：深度 × 挂靠

深度（改不改模型）和挂靠（答案是否依赖今天这条事实）是两件事：

| | 强挂靠 | 弱挂靠 |
|---|---|---|
| **深** | 目标：今天才有意义，且答完要改口 | 好课堂题，但换一天还能问，会重复 |
| **浅** | 新闻点评 | 鸡汤 |

判掉一条问题，最常见的原因不是「不够深」，而是**挂靠不够**：
问题很好，但今天的事实撑不住它，答起来只能猜。这种要等事实补齐再升格，不要硬发。

## 什么样的不是问题

- **作文题**：「我们应该如何看待 X？」——这是让你写文章，不是让你答问题。
- **预测题**：「这轮狂欢还能持续多久？」——不可判定，答完模型不动。
- **站队题**：「这是不是泡沫破裂的信号？」——两个大词都没定义，答完只是选边。
- **百科题**：「什么是自由现金流？」——一搜就有，是知识不是问题。
- **换名词题**：把今天的具体名词换掉，问题一模一样——说明它没挂在今天。

## 一条自检

把问题念给一个聪明但没背景的人听。如果他第一反应是「这还用问」，
然后三秒后改口说「……好像也没那么简单」，这条就对了。
