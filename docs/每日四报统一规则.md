# 每日四报统一规则

> 2026-11-09 定稿（原「三报」版）；新增心理学日报后改为四份。
> 以后用户说「更新今天日报」「出今天的日报」时，默认按本文件执行。
> 单份定时任务仍按各自的作业说明跑；**同一天由人一次性触发四份时，以本文件为准**。

## 1. 一次做四份，不拆开

默认范围固定为四份，缺一不可：

| 日报 | 目录 | 期号 | 条数 |
|---|---|---|---|
| AI 日报 | `daily-ai/` | 上一期 +1 | 5–9（建议 8–9） |
| 经济日报 | `daily-economy/` | 上一期 +1 | 4–9（常态 5–9） |
| 教育日报 | `daily-education/` | 上一期 +1 | 3–9（常态 4–9） |
| 心理学日报 | `daily-psychology/` | 上一期 +1 | 3–9（常态 4–9） |

- 四份都要**中英双语**：`YYYY-MM-DD.html` 与 `YYYY-MM-DD-en.html`。
- 不要做完一份就停；四份都发布、都验收，才算完成。
- 某一份当天确实不够合格新闻，按该份自己的下限少发，并在交付说明里写清原因；不凑数、不编。
- 心理学日报 2026-11-09 创刊（第 001 期）。创刊号因没有上一期，用了 `11/05 00:00 – 11/09 13:45` 的较长窗口；从第 002 期起必须接上一期终点，回到正常节奏。

## 2. 四份共用一个窗口终点

- 起点：各版块分别接自己上一期的 `windowEnd`，用 `node scripts/coverage.mjs window --section ai|economy|education|psychology` 查。
- 终点：四份取**同一个时刻**，不要各算各的「现在」。
- 如果当天 09:30 有例行数据发布（CPI/PPI 等）、且经济日报要把它写进头条，就等数据落地后再把四份一起收口；不需要等的时候，按实际完成时间收口。
- 窗口不能重叠、不能留空档；发布脚本的 `coverage.mjs check` 必须全绿。
- 2026-11-09 的实际窗口是 `11/08 13:08 – 11/09 09:31`，可作为「上午收口」的参照；心理学日报创刊号是当日 13:45 单独收口的例外。

## 3. 发布顺序

按 **AI → 经济 → 教育 → 心理学** 的顺序发布，便于后一份先读前一版块当天写了什么，避免头条和角度撞车：

```bash
node scripts/publish-daily.mjs      daily-ai/$DATE.html         --en daily-ai/$DATE-en.html         --push
node scripts/publish-economy.mjs    daily-economy/$DATE.html    --en daily-economy/$DATE-en.html    --push
node scripts/publish-education.mjs  daily-education/$DATE.html  --en daily-education/$DATE-en.html  --push
node scripts/publish-psychology.mjs daily-psychology/$DATE.html --en daily-psychology/$DATE-en.html --push
```

- 链接检查默认开启；出现「读不到标题」的，必须自己打开核对，能换源就换源。
- 发布后确认线上 `https://kaixinguor.com/daily-ai/$DATE`、`/daily-economy/$DATE`、`/daily-education/$DATE`、`/daily-psychology/$DATE` 都是 200。

## 4. 公众号贴图：只做 AI 日报

- 四份里**只有 AI 日报**生成微信公众号「图片消息」，固定 **5 张 1080×1440**：
  `01-cover` → `02-story-1` → `03-story-2` → `04-story-3` → `05-overview`。
- 经济日报、教育日报、心理学日报**不出图**，只发站内中英双语和 RSS；不要对它们跑 `make-social.mjs`。
- 生成命令：

  ```bash
  node scripts/make-social.mjs daily-ai/$DATE.html
  ```

- 封面版式按 [`社交配图规则.md`](社交配图规则.md) 第 2.1 节：
  - **封面不再放当天 headline 大标题**，避免和 02 重点页标题重复；
  - 摘要下面列 **「今日三条」**，对应 02–04 三张重点图，和网页 TL;DR 的选条一致；
  - 封面保留日期、摘要、三条索引、声明和统计条。
- 同时交付 `daily-ai/social/$DATE/公众号-图片消息.md`（标题、描述、逐图说明、发布步骤）。
- 图片只在本地生成，`daily-ai/social/` 已在 `.gitignore`，不提交、不部署。

## 5. 交付前验收

- [ ] 八份页面都能被 `parseIssue` 解析：期号、日期、条数、窗口一致。
- [ ] 四份窗口终点相同，且与上一期首尾相接；无跨期重复。
- [ ] 链接检查 0 条打不开；需人工确认的已逐条打开。
- [ ] 四个版块首页与八份线上页面均返回 200。
- [ ] AI 日报 5 张图齐全、尺寸 1080×1440，封面是「摘要 + 今日三条」。
- [ ] `git status` 干净，四份发布提交都已 push。
- [ ] 最终回复给出四份链接、各条数/头条、图片路径和发布文案路径。
