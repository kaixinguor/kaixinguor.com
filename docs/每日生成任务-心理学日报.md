# 每日生成任务 · 心理学日报（给定时 Agent 的作业说明）

> 每天 10:30（Asia/Shanghai）的定时任务要执行的内容。
> 工作目录：站点仓库根目录（服务器上是 `/opt/kaixinguor/site`，本机是 `~/deepseek-harness/web-kaixinguor.com/site`）。
> 源稿与成品都在 `daily-psychology/`（与 `daily-ai/`、`daily-economy/`、`daily-education/` 平级）。
> 创刊：2026-11-09（第 001 期，创刊号窗口 11/05 00:00 – 11/09 13:45）。
> 同一天四份一起生成时，先读 [每日四报统一规则](每日四报统一规则.md)。

这份说明和教育日报那份是一对：流程一样，选题口径不同。四份日报的分工见第 3 节。

## 0. 先做幂等检查

```bash
cd /opt/kaixinguor/site
TZ=Asia/Shanghai date '+%F %T %Z'
git pull --ff-only

NOW="$(TZ=Asia/Shanghai date +%H%M)"
if [ "$NOW" -lt 1030 ]; then
  KAIXINGUOR_NOTIFY_NAME="心理学日报" /opt/kaixinguor/bin/notify.sh info "心理学日报：当前早于 10:30，跳过补跑，等待今天 10:30"
  exit 0
fi

DATE="$(TZ=Asia/Shanghai date +%F)"
```

如果 `daily-psychology/$DATE.html` 与 `daily-psychology/$DATE-en.html` 都存在且非空：

- 不要重复生成、不要重复提交；
- `notify.sh success "心理学日报 $DATE 已存在，跳过重复生成"`；
- 结束。

### 0.1 手动触发时

服务器还没部署，日报是**手动跑**的：人发一句「出今天的心理学日报」，Agent 照这份说明执行。手动跑时：

- **不要**因为「早于 10:30」就退出；
- **不要**因为「今天已经有了」就跳过——手动重跑是有意的，`publish-psychology` 会覆盖同一天的文件，期号沿用已有的。

## 1. 时间窗口

- 窗口不是「现在往前推 24 小时」，而是**上一期的终点 → 现在**，两期首尾相接。
- 开工前先跑：

  ```bash
  node scripts/coverage.mjs window --section psychology
  ```

  它会打印本期应该用的 `start` / `end`：`start` 就是上一期的 `windowEnd`。
- **创刊号例外**：第 001 期没有上一期，用了 `11/05 00:00 – 11/09 13:45` 的 4 天窗口，把创刊前的几条重要稿子收进来。从第 002 期起必须接第 001 期的 `windowEnd`，回到正常节奏。
- **同一天重跑**：如果当天页面已经存在，`window` 会直接打印当天已记录的窗口——沿用，不要按当前时间重算；改了窗口会被发布检查拒绝。
- 窗口**不能重叠**，也**不能留空档**。发布脚本会检查，重叠直接拒绝发布。
- 只收**发布时间**落在这个窗口内的报道。页面上没有时间就打开原文确认；确认不了就放弃。
- 不把前一天的旧闻重新包装。**特别注意**：心理学研究经常「论文先 online、新闻晚几天、中文号再晚几周」，三者日期都要看；如果中文稿只是几个月前论文的迟到的翻译，不算当天新闻。

## 2. 检索与核验

至少做 3 轮、累计 10 个以上不同角度的查询。心理学这条线建议按下面的角度铺：

- **社会与行为**：孤独、社交媒体、青少年、职场倦怠、家庭与亲密关系、行为公共政策、大规模调查
- **临床与服务**：抑郁焦虑、睡眠、创伤、心理治疗、精神科门诊、危机干预、热线、基层服务能力
- **技术与产业**：数字疗法、AI 聊天机器人、神经调控、心理测评、心理健康 App、保险支付
- **研究与方法**：随机对照试验、元分析、纵向队列、神经影像、可重复性、预注册
- **政策与监管**：国家卫生健康委、教育部、医保局、地方卫健部门、行业规范与伦理指南
- **国际**：WHO、NIMH、APA、Lancet Psychiatry、JAMA Psychiatry、Nature Mental Health 等

每条候选都要：

1. **先打开原文，再决定收不收。** 打不开的一律不收录——包括 403 / 反爬、登录墙、付费墙、只有搜索摘要的情况。
2. 打不开就**整条删掉**，不要用转载顶替、不要凭标题补写正文、不要猜数字。
3. 打开后核对：标题、发布时间、正文首段是否与你要写的那件事一致。
4. 记录**时间（MM/DD HH:MM，北京时间）**、来源名、原文链接。
5. 优先原始来源（期刊页面、大学新闻稿、医院/卫健委通报、试验注册号）；只有二传来源时，在正文里写清楚「据……报道」。
6. 链接发布前会由脚本逐条请求，非 2xx 直接拦住、不落盘。

### 2.1 来源分级：只收一级和二级

> 这一节和四份作业说明的同名章节保持一致。改规则时一起改。

| 级别 | 是什么 | 怎么用 |
|---|---|---|
| **一级** | 同行评议论文、期刊社论、大学/研究机构新闻稿、WHO/NIMH 等机构报告、卫健委/教育部/医保局文件、医院官方公告、临床试验注册 | 优先。数字以它为准 |
| **二级** | 原创报道：新华社、央视、光明日报、澎湃、财新、中国新闻周刊、Nature/Science 新闻、STAT、Medical Daily 等 | 可用。正文里写清「据……」 |
| **三级** | 转载、聚合、快讯汇编、门户二手整理、自媒体、机构软文、课程/咨询广告 | 不用 |
| **不可确认** | 打不开、读不到标题、看不到发布时间、页面是空壳 | **一律剔除，不讨论** |

四条硬规则：

1. **同一件事有一级来源时，链接给一级。** 例：大学新闻稿 + 期刊论文，优先给能打开的论文页或新闻稿，不转述二手号。
2. **一级来源只覆盖部分事实时，正文里用行内链接补第二个来源。**
3. **脚本报「读不到标题」的链接，必须处理掉。** 顺序是：换到能读的版本 → 在正文补一个可验证的镜像 → 都不行就删掉这条。
4. **门户转载稿按三级算，但可以当「镜像」用。** 它证明这篇报道存在、正文可读；原始出处仍写作者媒体。

> 一条判据：把链接发给别人，他点开能不能在十秒内看到标题、发布时间和那组数字。看不到，就不该出现在版面上。

### 2.2 心理学这条线特有的八个坑

1. **新闻稿 ≠ 论文。** 大学新闻稿会把「相关」写成「导致」、把「小鼠」写成「人类」。能打开论文摘要就以摘要为准；打不开就按新闻稿原话写，并注明「据 XX 大学新闻稿」。
2. **预印本不是定论。** bioRxiv / medRxiv / PsyArXiv 没有同行评议，必须写明「预印本，未经同行评议」；不要写成「研究证明」。
3. **相关不等于因果。** 横断面调查、社交媒体使用与孤独、屏幕时间与抑郁，最多写「相关」「关联」，不要写「导致」「造成」。
4. **样本量与小样本陷阱。** 几十人的 fMRI、几百人的在线问卷、动物实验，结论的适用范围完全不同；标题里必须带样本量或对象。
5. **自报数据的偏差。** 问卷测的是「你觉得自己多孤独」，不是「你实际有多少支持」；两者不能混写。
6. **商业落地不是疗效证据。** 「某技术落地」「某中心揭牌」「专家点赞」属于产业新闻，不是临床证据；看点要写清还需要什么证据（适应症、对照、随访、注册）。
7. **诊断与治疗的红线。** 不给出个人诊断、不推荐具体药物剂量、不写「治愈」；涉及自杀/自伤时，正文给求助热线，不做细节描写。
8. **中文稿的日期陷阱。** 公众号、门户转载经常晚于论文几个月；以**原始论文的 online 日期**或**原始报道的发布时间**判断是否在窗口内，不以转载页为准。

### 2.3 去重：同一件事只写一次

**什么算同一件事**：同一个研究 / 同一家机构 / 同一项政策 + 同一个动作，或同一组数字。即使媒体不同、标题不同、发布时间不同，也算同一件事。

- 生成前先看最近 7 期的头条与标题；`node scripts/coverage.mjs report` 会列出跨期相似对，以及同一天另外三份日报写了什么。
- 发布脚本默认跑 `coverage.mjs check`：同一版块的往期重复、窗口重叠会直接拒绝落盘；**同一天另外三个版块的重叠只提示、不拦发布**——同一件事可以在两份里各写一次，但要写出各自领域关心的角度和数字。
- 命中后的处理顺序：
  1. 优先删掉，换一条当天的新事件；
  2. 确实是追更（新进展、新数字、新样本），给卡片加 `data-followup="旧闻日期"`，并在正文写出至少一个旧条目没有的数字 / 结论；
  3. 只有确实要带病发布时才加 `--allow-overlap`，并在通知里说明原因。
- 窗口重叠是重复的第一大来源：先按第 1 节把窗口接上，再谈选条。

## 3. 和另外三份日报的分工

每天 09:00 发 AI 日报、09:30 发经济日报、10:00 发教育日报、10:30 发心理学日报。**头条尽量不撞，正文可以重叠，但要换一个问题。**

| | AI 日报 | 经济日报 | 教育日报 | 心理学日报 |
|---|---|---|---|---|
| 问的问题 | 谁发布了什么，能力到了哪一步 | 这笔钱从哪来，记在谁的表上 | 谁被教、谁在教、凭什么录取 | 人为什么这样想、这样做，干预有没有用 |
| 典型角度 | 模型、产品、融资额、榜单 | 利率、通胀、财政、财报、并购 | 政策文本、招生与学位、职教与就业 | 行为机制、临床证据、服务可及、技术与伦理 |
| 不写什么 | 课堂细节、临床疗效 | 心理机制、治疗方案 | 模型参数、神经科学 | 模型参数、央行操作、招生政策 |

同一天都要写同一件事时（比如「AI 陪伴」），心理学日报必须给出**不同的问题**——AI 日报写模型能力，心理学日报写它对孤独、依恋与求助行为的影响，以及证据强度。

**拿不出不同角度就不写，换一条。** 宁可少一条，不要换个说法重发一遍。

## 4. 选条与结构

- 三个栏目，按这个顺序：
  1. 社会与行为（`data-c="society"`）
  2. 临床与服务（`data-c="clinic"`）
  3. 技术与产业（`data-c="industry"`）
- **条数不固定，按当天的信息密度。** 3–9 条是常态；创刊号是 7 条。
- **少于 3 条就不发**，发一条通知写明原因。不要为了凑数把旧闻、软文、没有原文的东西塞进来。
- 每个栏目至少 1 条；单个栏目最多 4 条。确实某个栏目当天没有合格新闻，可以缺栏目，但要在通知里说明。
- 头条：当天最能量化、影响面最大的那条，放在第一栏第一条。
- 每张卡片必须有：
  - 时间（MM/DD HH:MM 或只有 MM/DD）
  - 来源名 + 原文链接
  - 标题（陈述句，不用「震惊」「炸裂」）
  - 3–5 段事实，**带具体数字**
  - 1 段「看点」

**看点写什么**：写机制，不写态度。三选一——

- 这个发现改变了哪个原本的判断，证据强度够不够；
- 这项服务/技术改变了谁的激励与成本（患者、医院、支付方、平台）；
- 这个数字最后落在谁身上（患者自费、医生时间、企业采购、公共财政）。

不要写「值得关注」「拭目以待」「未来可期」，不要做疗效预测，不要把正文复述一遍。

### 4.1 写作视角：以「懂研究的临床观察者」的眼睛看

写「看点」之前先选角色：**心理学日报的作者是一个受过研究方法训练、也见过真实门诊的人**——知道随机对照和横断面调查的区别，也知道量表分数不等于一个人的生活。

他会这样问：

- 这个结论来自什么设计（RCT / 队列 / 横断面 / 动物 / 个案），能推到谁身上；
- 效应量有多大，和现有治疗/服务比是不是更好；
- 谁付钱、谁执行、谁受益，落地要过几道关；
- 有没有更便宜、更可及的替代方案。

他不写：模型参数、资本市场涨跌、没有出处的「心理学小技巧」。

**主视角与副视角。** 每条卡片有一个主视角（本份日报的角色），「看点」末尾可以加**一句**副视角——只在两件事同时成立时才加：

1. 这件事在另一个领域有独立的后果（支付、政策、公共健康）；
2. 这一句能给出一个新的数字、一个新的承担者，或者一个新的时间尺度。

副视角写成一句话，不单独成段，不重复主视角已经说过的话。

## 5. 写中英两版

中文：`daily-psychology/$DATE.html`
英文：`daily-psychology/$DATE-en.html`

- 期号：在最近一期基础上 +1（中文「第 00X 期」，英文「Issue 00X」）。
- 日期、星期、窗口、条数、阅读时长两边一致。
- **英文是重写，不是翻译。** 标题、导语、速览、看点这四处必须重新组织句子；机构名、研究名、数字要准确。
- 研究名、量表名、机构名首次出现给中英对照；论文给期刊名，不给「某研究」。
- 结构照抄最近一期（masthead / tldr / chapter / card / footer），只换内容。不要加 `<style>`。
- 英文 TL;DR 的粗体句末要留一个空格再接下一句。

## 6. 发布

```bash
cd /opt/kaixinguor/site
node scripts/publish-psychology.mjs "daily-psychology/$DATE.html" \
  --en "daily-psychology/$DATE-en.html" \
  --push
```

脚本会：

- 生成 `daily-psychology/$DATE.html` 和 `daily-psychology/$DATE-en.html`；
- 重新生成 `psychology.html` 的今日区与往期抽屉、`feed-psychology.xml`、`feed-psychology-en.xml`、`sitemap.xml`；
- **去重检查默认开启**：同一版块的往期重复、窗口重叠会直接拒绝落盘；同一天另外三个版块的重叠只提示不拦，确认侧重点不同即可；
- **链接检查默认开启**，非 2xx 直接失败、不落盘。

### 6.1 配图

心理学日报**不出公众号配图**，只发站内 HTML（中英双语）和 RSS。

- 不要对 `daily-psychology/` 跑 `make-social.mjs`；脚本会直接拒绝。
- 原因：公众号只发 AI 日报；四份日报里只有 AI 日报做图片消息。

发布后看一眼：

```bash
curl -sS -o /dev/null -w '%{http_code}\n' "https://kaixinguor.com/daily-psychology/$DATE.html"
curl -sS -o /dev/null -w '%{http_code}\n' "https://kaixinguor.com/psychology.html"
```

## 7. 通知

成功：

```bash
KAIXINGUOR_NOTIFY_NAME="心理学日报" /opt/kaixinguor/bin/notify.sh success \
  "心理学日报 $DATE 已发布 · N 条 · https://kaixinguor.com/psychology.html"
```

失败：

```bash
KAIXINGUOR_NOTIFY_NAME="心理学日报" /opt/kaixinguor/bin/notify.sh failure \
  "心理学日报 $DATE 生成失败：<一句话原因>。详见 journalctl -u kaixinguor-dsh -n 120"
```

当天不够 3 条、主动不发时，用 `info` 而不是 `failure`。通知失败不能反过来让任务失败。
