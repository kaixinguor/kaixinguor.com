# 每日生成任务 · 教育日报（给定时 Agent 的作业说明）

> 每天 10:00（Asia/Shanghai）的定时任务要执行的内容。
> 工作目录：站点仓库根目录（服务器上是 `/opt/kaixinguor/site`，本机是 `~/deepseek-harness/web-kaixinguor.com/site`）。
> 源稿与成品都在 `daily-education/`（与 `daily-ai/`、`daily-economy/` 平级）。
> 创刊：2026-11-03（第 001 期）。

这份说明和经济日报那份是一对：流程一样，选题口径不同。三份日报的分工见第 2 节。

## 0. 先做幂等检查

```bash
cd /opt/kaixinguor/site
TZ=Asia/Shanghai date '+%F %T %Z'
git pull --ff-only

NOW="$(TZ=Asia/Shanghai date +%H%M)"
if [ "$NOW" -lt 1000 ]; then
  KAIXINGUOR_NOTIFY_NAME="教育日报" /opt/kaixinguor/bin/notify.sh info "教育日报：当前早于 10:00，跳过补跑，等待今天 10:00"
  exit 0
fi

DATE="$(TZ=Asia/Shanghai date +%F)"
```

如果 `daily-education/$DATE.html` 与 `daily-education/$DATE-en.html` 都存在且非空：

- 不要重复生成、不要重复提交；
- `notify.sh success "教育日报 $DATE 已存在，跳过重复生成"`；
- 结束。

### 0.1 手动触发时

服务器还没部署，日报是**手动跑**的：人发一句「出今天的教育日报」，Agent 照这份说明执行。手动跑时：

- **不要**因为「早于 10:00」就退出；
- **不要**因为「今天已经有了」就跳过——手动重跑是有意的，`publish-education` 会覆盖同一天的文件，期号沿用已有的。

## 1. 时间窗口

- 窗口不是「现在往前推 24 小时」，而是**上一期的终点 → 现在**，两期首尾相接。
- 开工前先跑：

  ```bash
  node scripts/coverage.mjs window --section education
  ```

  它会打印本期应该用的 `start` / `end`：`start` 就是上一期的 `windowEnd`。
- **同一天重跑**：如果当天页面已经存在，`window` 会直接打印当天已记录的窗口——沿用，不要按当前时间重算；改了窗口会被发布检查拒绝。
- 窗口**不能重叠**，也**不能留空档**。发布脚本会检查，重叠直接拒绝发布。
- 只收**发布时间**落在这个窗口内的报道。页面上没有时间就打开原文确认；确认不了就放弃。
- 不把前一天的旧闻重新包装。政策类稿件尤其要看文号与成文日期：**成文日期**和**发布日期**经常差两三周。

## 2. 检索与核验

至少做 3 轮、累计 10 个以上不同角度的查询。教育这条线建议按下面的角度铺：

- **政策与监管**：教育部及司局、国务院、地方教育厅、市场监管局、法院判决、行政处罚决定
- **学校与招生**：高考报名与录取、考研、学位授权、招生计划调整、学校更名与转设、校园安全
- **职教与就业**：产教融合共同体、现场工程师、职业本科、技能大赛、毕业生就业数据
- **技术与产品**：教育大模型、智慧课堂、教育装备、学习机、AI 教师助手
- **行业与资本**：上市公司财报、并购、融资、IPO、教育消费数据、留学中介与培训监管
- **国际**：留学签证政策、国际学生流动、海外校区、国际组织（UNESCO / OECD / 世界银行）报告

每条候选都要：

1. **先打开原文，再决定收不收。** 打不开的一律不收录——包括 403 / 反爬、登录墙、付费墙、只有搜索摘要的情况。
2. 打不开就**整条删掉**，不要用转载顶替、不要凭标题补写正文、不要猜数字。
3. 打开后核对：标题、发布时间、正文首段是否与你要写的那件事一致。
4. 记录**时间（MM/DD HH:MM，北京时间）**、来源名、原文链接。
5. 优先原始来源（教育部官网、地方教育局通报、学校官网、统计公报、上市公司公告）；只有二传来源时，在正文里写清楚「据……报道」。
6. 链接发布前会由脚本逐条请求，非 2xx 直接拦住、不落盘。

### 2.1 来源分级：只收一级和二级

> 这一节和三份作业说明的同名章节保持一致。改规则时一起改。

| 级别 | 是什么 | 怎么用 |
|---|---|---|
| **一级** | 教育部及司局、国务院、地方教育行政部门、学校官网、法院判决、行政处罚决定书、上市公司公告与财报、国际组织新闻稿 | 优先。数字以它为准 |
| **二级** | 原创报道：中国教育报、光明日报、新华社、澎湃、财新、界面、多知网、芥末堆、泰晤士高等教育、Inside Higher Ed 等 | 可用。正文里写清「据……」 |
| **三级** | 转载、聚合、快讯汇编、门户二手整理、自媒体、招生中介软文 | 不用 |
| **不可确认** | 打不开、读不到标题、看不到发布时间、页面是空壳 | **一律剔除，不讨论** |

四条硬规则：

1. **同一件事有一级来源时，链接给一级。** 例：区教育局的处罚通报，链接给政府门户的通报原文，不是转述它的稿子。
2. **一级来源只覆盖部分事实时，正文里用行内链接补第二个来源。**
3. **脚本报「读不到标题」的链接，必须处理掉。** 顺序是：换到能读的版本 → 在正文补一个可验证的镜像 → 都不行就删掉这条。
4. **门户转载稿按三级算，但可以当「镜像」用。** 它证明这篇报道存在、正文可读；原始出处仍写作者媒体。

> 一条判据：把链接发给别人，他点开能不能在十秒内看到标题、发布时间和那组数字。看不到，就不该出现在版面上。

### 2.2 教育这条线特有的六个坑

1. **「学校 vs 机构」。** 教育培训机构常以「学校」「学院」自称。没有办学许可证的，正文要写「机构」，不要写成「学校」。
2. **升学率与就业率的口径。** 「一本率」「对口就业率」「初次就业率」分母各不相同；写数字必须带分母口径，拿不到分母就只写原文表述。
3. **成文日期 ≠ 发布日期。** 教育部文件经常先印发、后公布；标题里的日期可能是成文日。以官网发布的页面时间为准，正文里注明文号。
4. **征求意见稿不是政策。** 「拟」「将」「征求意见」三个阶段不能写成「已实施」。
5. **招生数据要看年份与省份。** 「2027 年高考报名人数」和「2026 年录取人数」是两件事；跨省比较要先确认口径一致。
6. **机构软文。** 留学中介、培训机构投放的「名校录取榜」「提分案例」，属于三级来源，不收录。

### 2.3 去重：同一件事只写一次

**什么算同一件事**：同一个主体（学校 / 机构 / 部门 / 政策）+ 同一个动作，或同一组数字。即使媒体不同、标题不同、发布时间不同，也算同一件事。

- 生成前先看最近 7 期的头条与标题；`node scripts/coverage.mjs report` 会列出跨期相似对，以及同一天另外两份日报写了什么。
- 发布脚本默认跑 `coverage.mjs check`：同一版块的往期重复、窗口重叠会直接拒绝落盘；**同一天另外两个版块的重叠只提示、不拦发布**——同一件事可以在两份里各写一次，但要写出各自领域关心的角度和数字。
- 命中后的处理顺序：
  1. 优先删掉，换一条当天的新事件；
  2. 确实是追更（新进展、新数字、新决定），给卡片加 `data-followup="旧闻日期"`，并在正文写出至少一个旧条目没有的数字 / 文号；
  3. 只有确实要带病发布时才加 `--allow-overlap`，并在通知里说明原因。
- 窗口重叠是重复的第一大来源：先按第 1 节把窗口接上，再谈选条。

## 3. 和三份日报的分工

每天 09:00 发 AI 日报、09:30 发经济日报、10:00 发教育日报。**头条尽量不撞，正文可以重叠，但要换一个问题。**

| | AI 日报 | 经济日报 | 教育日报 |
|---|---|---|---|
| 问的问题 | 谁发布了什么，能力到了哪一步 | 这笔钱从哪来，记在谁的表上 | 谁被教、谁在教、凭什么录取、监管怎么落地 |
| 典型角度 | 模型、产品、融资额、榜单 | 利率、通胀、财政、财报、并购 | 政策文本、招生与学位、职教与就业、课堂里的工具 |
| 不写什么 | 课堂细节、招生政策 | 教育治理、学校运行 | 模型参数、央行操作 |

两边都要写同一件事时（比如「AI 进校园」），教育日报必须给出**不同的问题**——AI 日报写模型能力，教育日报写学校怎么采购、教师怎么培训、经费从哪个科目出。

**拿不出不同角度就不写，换一条。** 宁可少一条，不要换个说法重发一遍。

## 4. 选条与结构

- 四个栏目，按这个顺序：
  1. 政策与监管（`data-c="policy"`）
  2. 职教与就业（`data-c="career"`）
  3. 技术与产品（`data-c="tech"`）
  4. 行业与资本（`data-c="capital"`）
- **条数不固定，按当天的信息密度。** 5–9 条是常态；创刊号是 9 条。
- **少于 3 条就不发**，发一条通知写明原因。不要为了凑数把旧闻、软文、没有原文的东西塞进来。
- 每个栏目至少 1 条；单个栏目最多 4 条。确实某个栏目当天没有合格新闻，可以缺栏目，但要在通知里说明。
- 头条：当天最能量化、影响面最大的那条，放在第一栏第一条。
- 每张卡片必须有：
  - 时间（MM/DD HH:MM 或只有 MM/DD）
  - 来源名 + 原文链接
  - 标题（陈述句，不用「震惊」「炸裂」）
  - 3–5 段事实，**带具体数字**
  - 1 段「看点」

**看点写什么**：写机制，不写态度。三选一——

- 这个政策改变了谁的激励（学校、教师、家长、企业）；
- 成本最后落在谁身上（财政、家庭、教师时间、学生）；
- 这个数字改变了哪个原本的判断。

不要写「值得关注」「拭目以待」「未来可期」，不要做升学与就业的预测，不要把正文复述一遍。

### 4.1 写作视角：以教育政策研究者的眼睛看

写「看点」之前先选角色：**教育日报的作者是一个研究教育政策的人，同时熟悉学校的实际运行**——知道一项政策从部委到课堂要经过几层，也知道校长和教师手里有什么、缺什么。

他会这样问：

- 谁被教、谁在教、凭什么录取、钱和人怎么配；
- 政策落地要过几道关：发文、配套、经费、编制、评价；
- 学校有没有人手接得住，教师的时间从哪里挤出来；
- 家庭要承担多少，负担会不会转给家长。

他不写：模型参数、资本市场涨跌。

## 5. 写中英两版

中文：`daily-education/$DATE.html`
英文：`daily-education/$DATE-en.html`

- 期号：在最近一期基础上 +1（中文「第 00X 期」，英文「Issue 00X」）。
- 日期、星期、窗口、条数、阅读时长两边一致。
- **英文是重写，不是翻译。** 标题、导语、速览、看点这四处必须重新组织句子；机构名、政策名、数字要准确。
- 政策与机构名首次出现给中英对照；文件给文号，不给「某文件」。
- 结构照抄最近一期（masthead / tldr / chapter / card / footer），只换内容。不要加 `<style>`。

## 6. 发布

```bash
cd /opt/kaixinguor/site
node scripts/publish-education.mjs "daily-education/$DATE.html" \
  --en "daily-education/$DATE-en.html" \
  --push
```

脚本会：

- 生成 `daily-education/$DATE.html` 和 `daily-education/$DATE-en.html`；
- 重新生成 `education.html` 的今日区与往期抽屉、`feed-education.xml`、`feed-education-en.xml`、`sitemap.xml`；
- **去重检查默认开启**：同一版块的往期重复、窗口重叠会直接拒绝落盘；同一天另外两个版块的重叠只提示不拦，确认侧重点不同即可；
- **链接检查默认开启**，非 2xx 直接失败、不落盘。

### 6.1 配图

教育日报**不出公众号配图**，只发站内 HTML（中英双语）和 RSS。

- 不要对 `daily-education/` 跑 `make-social.mjs`；脚本会直接拒绝。
- 原因：公众号只发 AI 日报；三份日报里只有 AI 日报做图片消息。

发布后看一眼：

```bash
curl -sS -o /dev/null -w '%{http_code}\n' "https://kaixinguor.com/daily-education/$DATE.html"
curl -sS -o /dev/null -w '%{http_code}\n' "https://kaixinguor.com/education.html"
```

## 7. 通知

成功：

```bash
KAIXINGUOR_NOTIFY_NAME="教育日报" /opt/kaixinguor/bin/notify.sh success \
  "教育日报 $DATE 已发布 · N 条 · https://kaixinguor.com/education.html"
```

失败：

```bash
KAIXINGUOR_NOTIFY_NAME="教育日报" /opt/kaixinguor/bin/notify.sh failure \
  "教育日报 $DATE 生成失败：<一句话原因>。详见 journalctl -u kaixinguor-dsh -n 120"
```

当天不够 3 条、主动不发时，用 `info` 而不是 `failure`。通知失败不能反过来让任务失败。

## 8. 纪律

- **打不开的来源一律不收录，宁可少发一条，也不凭标题、摘要或记忆补写。**
- **不和当天的 AI 日报、经济日报重复做头条。**
- 数字以原文为准；招生、就业、经费数字必须带口径与年份。
- 只改日报相关文件；不要改 `style.css`、工具页、隐私页。
- 不要 `git push --force`，不要重写历史。
- 不要提交密钥、token、`.env`。
- 已发布的某条事后发现原文失效：换一条能打开的原始来源，或者下架该条。
- **只发站内（HTML + RSS），不出公众号贴图。**
- 如果当天确实没有足够合格的教育新闻，宁可不发，也不要编。

## 9. 发布前自检（逐条过）

- [ ] 每条都有可打开的原文链接，且我打开过
- [ ] 每条点开都能在十秒内看到标题、发布时间、那组数字
- [ ] 有一级来源的，链接给了一级；只覆盖部分事实的，正文补了行内来源
- [ ] 政策稿区分了「征求意见」「已印发」「已实施」
- [ ] 没有三级来源（转载、聚合、机构软文）当出处
- [ ] 每条正文里至少有 2 个具体数字，且带口径（分母、年份、比例还是百分点）
- [ ] 看点里没有复述事实，没有「值得关注」
- [ ] 头条是当天影响面最大的那条，不是最好写的那条
- [ ] 和今天 AI 日报、经济日报的头条不重复
- [ ] 中英文的标题、导语、速览、看点都是各自重写的
- [ ] `publish-education` 的链接检查全绿

## 10. 更正

- 链接失效 → 换源重发，不发更正；
- 数字错 / 事实不成立 → 在 `issue-footer` 的声明**之前**加一段，写清改了什么、依据什么、什么时候改的：

```html
<p class="correction"><b>更正</b> 11 月 3 日：本条第 2 段的「XX」应为「YY」，依据原文已改。（11/04）</p>
```

不要静默改。读的人要能看到改动痕迹。
