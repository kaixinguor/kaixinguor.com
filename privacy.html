隐私政策

适用于 macOS 应用「课堂字幕」（英文名 Hark）。最后更新：2026-10-24。

一句话

我们不收集你的任何数据。没有账号、没有服务器、没有统计。你的录音、文字、API Key 全部留在你自己的电脑上。

声音是怎么处理的

  • App 通过 macOS 的 ScreenCaptureKit 获取电脑正在播放的声音，并在本机重采样。
  • 识别由 macOS 自带的 Speech 框架完成，全程离线，音频不会离开这台电脑。
  • 默认不把音频写入磁盘。识别完，内存里的音频就丢弃了。
  • 如果你在设置里打开「保留音频用于重跑」，App 会把音频存成本地 .wav 文件，供你课后用其他模型重新识别。这个文件只在你自己的磁盘上，我们无法访问。

文字存在哪

  • 逐字稿以 Markdown 文件形式保存在你本机的 ~/Library/Application Support/LiveClass/。
  • 删除 App 或手动删除文件夹，数据即消失。我们不保留任何副本。

「整理」功能与第三方 AI 服务

这是唯一会联网的功能，需要你主动触发（点「整理」按钮）。触发时：

  • App 会把逐字稿的纯文字内容发送到你自己配置的大模型服务（默认是 DeepSeek，也可以是任何兼容 OpenAI 接口的服务）。
  • 请求使用你自己的 API Key，费用由你与该服务商直接结算，我们不参与、不加价。
  • 音频绝不会被发送。只发文字。
  • 这些文字会受该服务商的隐私政策约束，请自行查阅。我们不接收、不存储、不中转这些内容。
  • 不配置 API Key，这个功能就不可用；免费版的全部功能都不受影响。

API Key 存在哪

存在 macOS 系统的钥匙串（Keychain）里，不是明文配置文件。只有本 App 能读取。

我们不收集什么

  • 不收集设备标识、位置、使用统计、崩溃日志。
  • 没有账号体系，不要求邮箱或手机号。
  • 不含任何第三方分析 SDK、广告 SDK。

系统权限

  • 屏幕与系统录音：macOS 把「电脑播放的声音」归在这个权限下。App 只取音频，画面被压到 2×2 像素、每秒 1 帧，不保存、不查看。
  • 语音识别：使用系统 Speech 框架所需。

两项权限都可以随时在「系统设置 → 隐私与安全性」里收回；收回后 App 无法工作，但已有文件不受影响。

儿童

本产品不面向 13 岁以下儿童，也不会有意收集其任何信息。

政策变更

如果这份政策有实质变更，会更新本页顶部的日期，并在 App 内提示。
