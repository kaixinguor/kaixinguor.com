11/11 10:00 阿里云百炼 ↗

阿里上线 Qwen4-Max 预览版：100 万 token 上下文、39 万 token 输出，只卖 Token Plan

阿里云 11 月 11 日 10:00 起开放 Qwen4-Max-Preview。它是 Qwen 家族的旗舰多模态模型，同时处理文本、图像和视频，支持函数调用、联网搜索、JSON Schema 结构化输出，并兼容 OpenAI 的 Chat Completions / Responses 与 Anthropic 的 Messages 接口。与以往不同，这一版只通过 Token Plan 提供，不支持按量付费；预览期到 11 月 25 日 24:00 结束，期间不再改动，到期后模型直接下线。调用走新加坡的专用端点，不在常规百炼按量计费链路上。

规格上，上下文 1,000,000 token，最大输出 393,216 token，且思考与最终答案共用这一份预算。思考默认开启，reasoning_effort 可选 low、medium、xhigh，默认 xhigh，不能再和 thinking_budget 同时设置。官方还改了一个容易踩的语义：从这一版起，OpenAI Chat Completions 里的 max_tokens 等同 max_completion_tokens，只限「思考 + 回答」的总量；过去按纯回答长度设的上限，现在可能把答案截断。多轮对话默认保留历史思考，要求客户端回传 assistant 消息里的 reasoning_content 字段。

文档没有给参数量、激活参数、基准分数或每百万 token 价格，只说明按 Token Plan 的 credits 计费。对开发者来说，这是一次「先试用、再选型」的发布：能测 1M 上下文里的长程检索、跨文件代码修改和多模态输入，但不能把它写进需要长期稳定的生产依赖。

看点1M 上下文配 39 万输出，明显是给长轨迹 agent 用的：一次任务里要放进去的代码库、日志、工具返回，都在这两个数字的预算内。真正要压测的是有效召回而不是「能塞多少」——把 80 万 token 的仓库丢进去，看它在第 60 万 token 处还能不能引用对文件；再测 thinking 预算被 xhigh 吃掉后，留给答案的 token 还剩多少。max_tokens 语义变化会静默破坏现有 SDK 的截断逻辑，升级前先跑回归。
另一个视角两周后下线意味着采购方无法把它列入年度预算，只能当作一次付费评测；真正的采购决策会被推到 Qwen4 正式版，而正式版的定价要等预览结束后才公布。

11/11 14:18 新华网 ↗

百度发布文心 5.5 Flash Preview：2800 亿总参数、140 亿激活，忙时输入 2 元 / 百万 token

百度 11 月 11 日发布文心 5.5 Flash Preview：总参数 2800 亿，每个 token 激活 140 亿，支持最长 100 万 token 上下文，生成速度超过 200 token/s。底层用了新的混合稀疏注意力、多路由器 MoE 和 ECHO 多 token 预测，官方称在提升能力的同时降低计算与显存开销；这一版还首次把自研的 RSI 技术用在推理优化上，由 ERNIE Evolve 参与模型推理。

能力侧重点有三个。编程覆盖从真实代码库修 bug 到完整搭建应用，并针对游戏开发做了专项训练；3D 建模强化了 Blender 和 CAD 的工具使用，能从文本推断形状、比例与空间关系，再转成程序化模型；知识工作要求多步交付表格、文档和演示文稿，官方给了 30 万个工作空间、1000 万份参考文件、40 多种文件类型的训练环境。视频创作侧则搭了 15 万个创作环境，覆盖创意、剧本、分镜、素材与配音，累计成片约 5300 分钟。

开发者今天就能在百度智能云千帆上通过 API 调用。定价为每百万 token 输入忙时 2 元、闲时 1 元，输出忙时 8 元、闲时 4 元，限时五折。模型权重计划在 11 月 25 日面向全球开源社区发布。

看点140 亿激活参数是这条发布里最硬的数字：它决定单卡能扛多少并发，也决定 200 token/s 是在什么 batch 下测出来的。1M 上下文靠稀疏注意力省算力，但稀疏模式会不会漏掉长文档中段的细节，要看检索类评测，而不是 Terminal-Bench。官方对基准只写「具有竞争力」，没给分数和对比对象——在权重 11 月 25 日开放之前，任何「追平某某」的说法都只能算厂商口径。对做私有化部署的团队，真正的时点是权重开放那天：能不能在两张 80GB 卡上跑起来，比 API 便宜几分钱更重要。

11/11 15:44 MiniMax ↗

MiniMax 开源 H3-Image：4K 图 10 秒内出，权重已上 Hugging Face

MiniMax 11 月 11 日发布 H3-Image，一个基于 H3 的开源权重图像模型，支持文生图、参考图生成和图像编辑。官方称它能在 10 秒内生成一张 4096×4096（约 1600 万像素）的 4K 图，速度最高是主流方案的 5 倍；最多可同时理解 16 张参考图，用来保持主体、风格或构图的一致性。权重已经放到 Hugging Face，API、MiniMax Code 和 Hailuo 同步上线。

速度来自整条后训练链路的调整，而不是单点技巧：数据、强化学习、采样步数压缩、PE 和部署优化一起改。官方给的对比是，Standard 模式比主流方案快 1.5–2 倍，Highspeed 模式快 3–4 倍；价格是同类主流产品的 50%–70%，发布首周 4K 及以上分辨率再打五折。模型卡和定价表都放在博客里，但没有给 FID、人工偏好或提示词遵循度的第三方分数。

看点4K/10 秒改变的是工作流而不是单张成本：设计师可以在一次会话里连出十几版，再挑一张放大，迭代次数上去了，单张价格反而没那么重要。16 张参考图是更难的部分——参考越多，身份泄漏和构图冲突越容易发生，官方没公开是怎么做 reference dropout 的。开源权重意味着可以把编辑链放进本地流水线，按 GPU 小时而不是按张计费；代价是要自己承担量化后的画质损失和 4K 显存占用。「快 5 倍」「50%–70% 价格」都是厂商自测，等第三方复现再写进采购对比表。

腾讯上线元宝搜索：so.qq.com 独立入口，索引覆盖公众号与视频号

腾讯 11 月 11 日正式上线「元宝搜索」。用户在任意浏览器地址栏输入 so.qq.com 就能使用，也可以把 QQ 浏览器升级到最新版，在引擎设置里切换为元宝搜索。它不是给元宝加一个搜索框，而是用元宝的大模型能力重做了「理解—检索—排序—答案组织」整条链路，依托千亿级索引，覆盖全网网页、公众号、视频号等腾讯生态内容和学术文献。

结果呈现上，官方说会优先展示权威机构与官方来源，并把广告与答案明确区分。对中文互联网来说，公众号和视频号一直是搜索引擎抓不到、或者抓不全的封闭语料；腾讯自己把它们接进索引，等于把独有数据变成了搜索质量的差异点。

看点搜索正在变成 agent 的检索层：模型再强，拿不到对的材料也答不对。腾讯的护城河不在模型分数，而在「公众号 + 视频号」这批别人拿不到的语料，以及 QQ 浏览器这个默认入口。「广告与答案分开」是产品承诺，不是技术保证——真正要看的是排序权重里商业内容占多少、标注是否稳定。对做 RAG 的团队，so.qq.com 会不会开放可引用的结构化结果，比它今天排第几更重要；如果不开放，它只是多了一个封闭的高质量中文源。

DeepMind 发布 AlphaGenome 2：按细胞类型条件化预测，因果变异召回率从 16% 提到 30%

Google DeepMind 当地时间 11 月 11 日发布 AlphaGenome 2，把上一代的「并行预测」改成了「条件模型」：输入一段 100 万字母的 DNA 序列，再指定一个生物条件——组织、细胞类型或细胞状态，模型每次只预测这一种条件下的结果。条件可以来自参考目录，也可以由科学家用自己的单细胞实验现场生成。上一代一次预测多种组织的数千个实验，效率高但容量被摊薄，难以分辨亲缘很近的细胞类型之间的细微差异。

训练数据包含人与小鼠的 bulk 与单细胞数据，合计超过 1.07 亿个单细胞剖面。输出覆盖基因表达、组蛋白修饰、染色质可及性，并新增了 DNA 甲基化。在 TenK10K 的 28 种原代免疫细胞上，AlphaGenome 2 找到的因果变异接近上一代在单细胞数据上微调后的两倍（30% 对 16%），方向性基因效应为 43% 对 23%；它还复现了一项 IBD 研究——远端调控开关上的变异通过过度激活肠道巨噬细胞里的 ETS2 基因致病，并指出该变异只影响这一种细胞。条件化结构还带来跨模态补全：输入单细胞基因活性一项测量，就能预测未测的染色质可及性。

可用性上，AlphaGenome 2 对非商业研究免费开放，商业研究走私有预览。代价是算力：细胞级精确推断比上一代更贵，DeepMind 的建议是分工——第一代模型负责构建覆盖全基因组 90 亿个变异的数据库，第二代只对候选位点做细胞级归因和靶点发现。

看点把「组织平均」换成「单细胞状态」，解决的是 GWAS 里最常见的一种失败：信号落在没有对应细胞类型的平均表达上，看起来显著，却找不到真正起作用的细胞。30% 的召回率值得记住，但它仍是召回率——七成的因果变异还是找不到；论文里更该看的是精度和校准，而不是单一召回数字。计算成本上升意味着它不适合全基因组扫描，适合做二阶段筛选：先用第一代把候选缩到几千个，再用第二代逐个细胞类型归因。对做生物基础模型的团队，cell encoder 能零样本迁移到新数据，这一条比跑分更有复用价值。

均胜电子 11 月 10 日对外披露，旗下宁波超平面机器人科技已向宇树科技交付首台机器人高算力大脑背包，双方合作从框架协议进入产品交付阶段，年内还会有更多项目进展。这个背包是均胜具身智能「大脑软硬一体」方案的核心产品：把高算力端侧平台和高能效能源系统做成可外挂的独立模块，兼容宇树的人形、四足和轮式多款机器人。

英国芯片公司 Fractile 融资 7.2 亿美元、估值 70 亿美元：把 DRAM 堆在逻辑上跑长上下文

英国 AI 芯片公司 Fractile 完成 7.2 亿美元融资，投后估值 70 亿美元。本轮由 Thrive、Founders Fund、Lightspeed 和 Redpoint 联合领投，Balderton 参投。公司 2022 年成立，做的不只是芯片：自研芯片、系统、软件，也自己做 ML 研究，属于少见的全栈型硅片公司。

Alibaba opens Qwen4-Max-Preview: a 1M-token context and 393,216-token output, Token Plan only

Alibaba Cloud opened Qwen4-Max-Preview at 10:00 Beijing time on November 11. It is the flagship multimodal model in the Qwen family, handling text, images and video, with function calling, web search and JSON Schema output; it is compatible with OpenAI's Chat Completions and Responses APIs and with Anthropic's Messages API. This release is different in one structural way: it is offered only through Token Plan, with no pay-as-you-go access. The preview runs until 24:00 on November 25, is frozen during that period, and the model is retired when it ends. Calls go through a dedicated Singapore endpoint rather than the normal metered Model Studio path.

The spec sheet lists a 1,000,000-token context and a maximum output of 393,216 tokens, with thinking and the final answer sharing that budget. Thinking is on by default; reasoning_effort accepts low, medium or xhigh, with xhigh as the default, and it cannot be combined with thinking_budget. Alibaba also changed a semantic that is easy to miss: from this model on, max_tokens in OpenAI Chat Completions equals max_completion_tokens and caps thinking plus answer together. A limit sized for the answer alone can now truncate it. Multi-turn chats keep historical thinking by default and expect the client to pass back the reasoning_content field on assistant messages.

The documentation gives no parameter count, no active-parameter figure, no benchmark scores and no per-token price; billing runs on Token Plan credits. For developers this is a trial-and-select release: you can test long-horizon retrieval across a 1M context, multi-file code changes and multimodal input, but you cannot make it a long-lived production dependency.

Why it mattersA 1M context with a 393,216-token output is clearly aimed at long-trajectory agents: the repository, the logs and the tool returns of one task all have to fit inside those two numbers. The thing to stress-test is effective recall, not raw capacity. Drop an 800k-token repo in and see whether it still cites the right file at token 600k; then measure how much of the answer budget survives after xhigh thinking takes its share. The max_tokens change will silently break truncation logic in existing SDK wrappers, so run a regression before upgrading.
The other viewRetiring the model after two weeks means procurement cannot put it in an annual budget; it is a paid evaluation, and the real purchase decision moves to the GA release, whose price will only be published after the preview ends.

Baidu releases ERNIE 5.5 Flash Preview: 280B total parameters, 14B active, 2 yuan per million input tokens

Baidu released ERNIE 5.5 Flash Preview on November 11: 280 billion total parameters, 14 billion activated per token, a context of up to one million tokens and a generation speed above 200 tokens per second. Under the hood are a new hybrid sparse attention scheme, a multi-router MoE and ECHO multi-token prediction, which Baidu says cut compute and memory cost while raising capability. The release also marks the first use of Baidu's in-house RSI technique in inference optimization, with ERNIE Evolve participating in inference.

The capability push lands in three places. Coding spans fixing bugs in real repositories to building whole applications, with extra training for game development. 3D modelling leans on Blender and CAD tool use: the model infers shape, scale and spatial relations from text and turns them into procedural models. Knowledge work targets multi-step deliverables such as spreadsheets, documents and decks, trained on 300,000 workspaces, 10 million reference files and more than 40 file types. On the video side Baidu built 150,000 creation environments covering ideas, scripts, storyboards, assets and voice-over, with roughly 5,300 minutes of finished video in total.

Developers can call it today through the Qianfan API. Pricing is 2 yuan per million input tokens at peak and 1 yuan off-peak; output is 8 yuan at peak and 4 yuan off-peak, with a limited-time 50% discount. The weights are scheduled to be released to the open-source community on November 25.

Why it mattersThe 14B active-parameter figure is the hardest number in the release: it decides how much concurrency one card can hold, and it frames the conditions under which 200 tokens a second was measured. Sparse attention is what makes a 1M context affordable, but whether the sparse pattern drops details in the middle of a long document is a retrieval question, not a Terminal-Bench question. Baidu describes its benchmark results only as "competitive" and publishes neither scores nor baselines; until the weights land on November 25, any claim of parity is vendor framing. For teams planning private deployment, the date that matters is weights day: whether it runs on two 80GB cards will decide more than a few fen of API price.

MiniMax open-sources H3-Image: 4K images in under ten seconds, weights on Hugging Face

MiniMax released H3-Image on November 11, an open-weight image model built on H3 that supports text-to-image, reference-based generation and editing. The company says it produces a 4096×4096 image — about 16 megapixels — in under ten seconds, up to five times faster than mainstream alternatives, and can reason over as many as 16 reference images at once to hold a subject, style or composition consistent. The weights are on Hugging Face, and the model is live in the API, MiniMax Code and Hailuo.

The speed comes from retuning the whole post-training pipeline rather than one trick: data, reinforcement learning, fewer sampling steps, PE and deployment optimization were changed together. MiniMax's comparison is 1.5–2× faster than mainstream in Standard mode and 3–4× in Highspeed mode, at 50–70% of comparable products' prices, with a further 50% off 4K-and-above requests during launch week. The blog includes a model card and a price chart but no FID, human-preference or prompt-adherence scores from a third party.

Why it matters4K in ten seconds changes the workflow rather than the cost of a single image: a designer can produce a dozen variants in one session, pick one and upscale, so iteration count rises and per-image price matters less. The harder engineering is the 16 reference images — the more references, the easier identity leakage and composition conflicts become, and MiniMax does not disclose its reference-dropout scheme. Open weights let teams put the edit chain inside a local pipeline and pay by GPU-hour instead of per image, at the cost of quantization loss and 4K VRAM. "Five times faster" and "50–70% of the price" are vendor measurements; wait for independent reproduction before putting them in a procurement table.

This is not a search box bolted onto the Yuanbao assistant: Tencent rebuilt the entire understand–retrieve–rank–answer chain on Yuanbao's model, backed by a trillion-scale index that covers the open web, WeChat official accounts, WeChat Channels and academic literature.

On presentation, Tencent says it prioritises authoritative institutions and official sources and clearly separates ads from answers. For the Chinese internet, WeChat official accounts and Channels have long been closed corpora that general search engines cannot crawl, or cannot crawl fully; bringing them into its own index turns that exclusive data into a quality differentiator.

Why it mattersSearch is becoming the retrieval layer for agents: a stronger model still answers wrong if it cannot fetch the right material. Tencent's moat is not a benchmark score but the WeChat article and video corpus that others cannot get, plus QQ Browser as a default entrance. "Ads separated from answers" is a product promise, not a technical guarantee; what matters is how much commercial content sits in the ranking weights and whether the labels stay stable. For RAG teams, the question is whether so.qq.com will expose citable structured results — if not, it is one more closed, high-quality Chinese source.

DeepMind's AlphaGenome 2 conditions on cell type, lifting causal-variant recall from 16% to 30%

Google DeepMind released AlphaGenome 2 on November 11 local time, replacing the previous generation's parallel prediction with a conditional model. It takes a million-letter DNA sequence plus one biological condition — a tissue, cell type or cell state — and predicts that condition alone. The condition can come from a reference catalogue or be generated on the fly from a scientist's own single-cell experiment. The first model predicted thousands of experiments across many tissues at once; efficient, but it spread capacity thin and struggled to separate closely related cell types.

Training covered human and mouse bulk and single-cell data, more than 107 million individual cell profiles in total. Outputs cover gene expression, histone modifications and chromatin accessibility, and now DNA methylation as well. On the 28 primary immune cell types in TenK10K, AlphaGenome 2 identified nearly twice as many causal variants as the original fine-tuned on single-cell data (30% versus 16%) and directional gene effects of 43% versus 23%. It also reproduced an IBD study in which a variant in a distant regulatory switch overactivates ETS2 in gut macrophages, singling out the causal variant and showing the effect is confined to that cell type. The conditional design also enables cross-modality imputation: from one measurement, such as single-cell gene activity, it predicts unmeasured chromatin accessibility.

AlphaGenome 2 is free for non-commercial research and in private preview for commercial work. The cost is compute: cell-level inference is more expensive than the previous generation, and DeepMind suggests a division of labour — the first model for genome-wide databases over all 9 billion variants, the second for cell-level attribution and target discovery on candidate sites.

Why it mattersSwapping a tissue average for a single-cell state addresses a common GWAS failure: a signal shows up on an average expression profile that no relevant cell type actually has, so it looks significant while pointing at the wrong cells. The 30% recall figure is worth remembering, but it is still recall — seven in ten causal variants remain unfound, and the paper's precision and calibration matter more than the headline number. Higher compute means it is not built for genome-wide scans; it fits a second-stage filter, after the first model narrows candidates to a few thousand. For teams building biological foundation models, the cell encoder's zero-shot transfer to new data is more reusable than any benchmark.

Joyson delivers its first high-compute "brain backpack" to Unitree, compatible with humanoid, quadruped and wheeled robots

Joyson Electronics said on November 10 that its Ningbo Hyperplane Robotics unit had delivered the first high-compute robot brain backpack to Unitree, moving the partnership from a framework agreement to product delivery, with more projects expected this year. The backpack is the core product of Joyson's embodied-AI hardware-software stack: a high-compute edge platform plus an energy system packaged as an external module compatible with several Unitree humanoid, quadruped and wheeled robots.

According to the company, it strengthens perception, data collection, autonomous decision-making and motion control, runs real-time inference for on-device embodied models, supports self-evolution of "physical agents" and extends continuous operating time through energy management. The two companies are also co-developing dexterous hands and a solid-state battery energy-management system, aiming at standardised parts that can be mass-produced across robot types. Industrially, they are working on automotive-parts lines: data collection, hardware and software adaptation, industrial model training, line pilots and then replication at scale.

Why it mattersA backpack is an engineering compromise that decouples compute from the body: the robot does not have to reserve power, cooling and structure for peak compute, at the cost of a power/data cable, extra weight and interface bandwidth as a new bottleneck. For embodied teams, the numbers to watch are sustained power draw, cooling at load and end-to-end latency, not TOPS — a powerful chip is useless if sensor data cannot get in and actions cannot get out fast enough. For Joyson, this ports automotive Tier-1 manufacturing into robot components; for Unitree, it buys a replicable compute module rather than a one-off custom build.

11/11 TechCrunch ↗

UK chip company Fractile raises $720m at a $7bn valuation, stacking DRAM on logic for long contexts

Fractile, a UK AI chip company, raised $720 million at a $7 billion post-money valuation. The round was co-led by Thrive, Founders Fund, Lightspeed and Redpoint, with Balderton joining. Founded in 2022, Fractile is unusually full-stack for a silicon company: it designs its own chips, systems and software, and does its own machine-learning research.

Its technical path differs from mainstream AI chips. Most rely on HBM and near-identical designs; Fractile packages DRAM directly on top of its logic die, which it says delivers far more memory bandwidth than HBM and more capacity than SRAM, so large models can run at thousands of tokens per second even at very long contexts. That figure is the company's own and has not been independently reproduced. The bet, as Fractile frames it, is that the bottleneck for frontier models moves from raw compute to how fast they produce useful output, and that fixing it requires rebuilding the hardware.

Why it mattersThe bottleneck in long-context inference is memory bandwidth and capacity, not FLOPs: the KV cache grows linearly with context, and HBM bandwidth and capacity bind together as batch rises. DRAM-on-logic trades advanced packaging for bandwidth, and the engineering bill arrives as yield, heat and DRAM supply — none of which a funding round solves. $720 million shows capital will back a non-HBM path, but the real validation is customer tape-outs, production yield and measured tokens per second, not a $7 billion mark. For cloud providers, a second memory path means bargaining power; for Nvidia, this is competition at the packaging layer rather than the process node.
