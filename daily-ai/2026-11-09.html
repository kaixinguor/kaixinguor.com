英伟达把 VLA 的推理文本从动作路径里摘掉：成功率不变，延迟最多降 3.4 倍

英伟达与纽约大学、UC 伯克利、约翰斯·霍普金斯、斯坦福的团队提出 TacitVLA：训练时照常让视觉语言主干生成推理文本，但在注意力掩码里让动作专家看不到这段文本。动作不再等待自回归解码，推理监督仍然塑造主干表示；论文与项目页已公开，代码标注为即将发布。

在 RoboMME、RMBench、LIBERO / LIBERO-Plus 和 PhysicalAI-AV 四个基准上，TacitVLA 的成功率与显式推理版本相当，单次调用延迟最多降低 3.4 倍。LIBERO 上为 147ms 对 495ms，正好卡进 250ms 的执行窗口；闭环驾驶为 127ms 对 269ms。在相同延迟下，它比不做推理训练的同一模型成功率最多高 17.1 个百分点。

绝对成绩：RoboMME 计数任务 82.7%（此前最好 66.8%），RMBench 77.5%（此前 56.5%），LIBERO-Plus 72.9%，PhysicalAI-AV 闭环场景分 52.5%。RMBench 的 Press Button 任务上 74.3%，不做推理的版本只有 7.7%，记忆条目正确率 99.7%。所有延迟数字都是单张 H100 上的均值。

看点这不是让模型「少想」，而是把推理的两种作用拆开：训练时写推理能改善主干，部署时读当前推理只会增加延迟。对做机器人的团队，最小改动是一行 attention mask，不需要新模型或调度器；真正要验证的是长程记忆任务里「动作先出、日志后写」能否稳定，以及跨机型迁移时推理监督是否还划算。
另一个视角延迟从 495ms 降到 147ms，省下的是产线节拍和 GPU 时间；如果每台机器人每天多跑三倍回合，数据回流成本会先于硬件成本成为瓶颈。

Karpathy 用 Claude 一个周末搭出 HackerTube：4300 万条评论筛出 6,454 个视频

Karpathy 用 Claude Opus 5.5 在一个周末搭出 HackerTube，从 Hacker News 20 年的 4300 万条评论里筛出 6,454 个被反复推荐的视频。页面不需要登录，只显示视频中段的一帧，状态存在浏览器本地。

他说 Claude Code 承担了从数据分析到服务器设置的几乎全部工作，自己只做了三件事：申请 Google Cloud API key、租服务器、买域名。随后又用 Claude Code「3 分钟一次成型」搭出 TristanTube，收录 47,000 个视频。

看点重点不是又一个视频站，而是「数据清洗 + 前端 + 部署」被压进一个周末的成本结构。可复现的部分是任务拆分与验收：先让模型把 20 年评论变成可查询的候选集，再让人只做域名、密钥和上线三步。难点在评估——推荐质量靠作者的主观判断，没有基准；这类「一人产品」越多，越需要可审计的构建日志。

上海交大 AutoDNA 登上《自然》：多智能体自主做分子生物学实验

上海交大计算机学院 IPADS 实验室陈海波、王肇国团队与化学化工学院樊春海、王飞团队合作，构建 AI 原生科学实验室 AutoDNA（思源一号），实现自主分子生物学实验操作。成果发表于《自然》，并获该刊官网首页头条报道。

架构上，多智能体把实验拆成文献检索、试剂选择、方案设计、代码生成、硬件执行、结果分析和迭代优化；仪器能力被抽象成带自然语言说明和统一代码接口的「原子服务」，模型可以组合设备能力、生成并修正跨设备控制代码。硬件提供微米级定位和微升级液体处理，控制终端基于 OpenHarmony。

团队已在核酸检测、酶促 DNA 合成、癌症检测等场景完成验证，并展示端到端 DNA 存储的编码、写入、保存、读取与解码流程。论文编号为 s41586-026-11228-6。

看点这条的工程价值在「仪器抽象层」：把不同型号设备的差异藏在一个可被模型调用的服务接口后面，才可能让 agent 跨设备编排。需要看的是失败模式——微米级定位在长时间运行下的漂移、污染控制，以及实验失败后能否自动回滚。对做实验室自动化的团队，先统一接口和状态机，再谈让模型自由生成代码；否则一次错误调用就可能毁掉整批样本。

美国司法部起诉三人用 AI 冒充高管与律师，涉案 1.29 亿美元

美国纽约南区联邦检察官办公室公布起诉书：三名嫌疑人雅各布·索尔、沙龙·哈赞、盖伊·谢特里特涉嫌自 2024 年至 2026 年用 AI 伪造企业高管和律师的声音、影像，诱骗员工汇款，涉案超过 1.29 亿美元。索尔和哈赞今年夏天在西班牙被捕，谢特里特 9 月在英国落网。

手法是两步：先冒充高管联系员工，称有敏感财务交易需要协助；再让员工与「国际律所律师」对接，由假冒律师指示汇款。赃款到账后被兑换成加密货币，再与其他共谋者瓜分。

已披露的受害者包括：密苏里州一家医院集团损失近 500 万美元、罗德岛州一家银行约 270 万美元、加州一家医院集团约 300 万美元、马萨诸塞州一家共同基金公司超过 460 万美元、佛罗里达州一家宠物食品公司约 500 万美元、一家英国科技公司超过 1,100 万美元。三人被控共谋电信欺诈、洗钱共谋和加重身份盗用。

看点这不是「深度伪造检测」的单点问题，而是授权链问题：员工被要求绕过正常的付款复核，因为对方「是高管、是律师」。修复顺序应是双人复核、回拨已知号码、付款白名单，而不是先买一个检测模型；对做语音和视频产品的团队，水印与来源凭证要默认开启，并且能被下游验证。

Co-Design Bench：十个编码智能体最好的也只完整做对 26.4% 的任务

阿里与多所亚洲高校的研究者用真实编码会话中的用户修改请求构建 Co-Design Bench，要求智能体改造现有 Web 应用，输入可以包含图片、音频、视频和文档。十个受测模型中最好的 GPT-6 Astra 平均满足约 70% 的任务要求，但只有 26.4% 的任务完全正确。

分轨道看，GPT-6 Astra 在多模态任务上完全做对 41%，在仓库级任务上不到 18%。Claude Opus 5 与 Qwen3.8-Max 紧随其后，Grok 4.6 垫底。任务同时包含布局、设计、交互、内容等多类修改时，所有模型都变差。

评测用两个 AI judge：一个在浏览器里操作成品，另一个复核所有正向判定并检查 mock-up 或硬编码；只有真正跑起来的功能才得分。另一个发现是 harness 影响很大：Qwen3.8-27B 在大改任务上，换环境可从 75% 掉到 56%，甚至改变两个模型的排名。

看点99% 的旧基准分数已经不能说明「能不能交付」，26.4% 才接近真实项目的体感。对采购编码 agent 的团队，应该把模型和工作环境成对测试，并把验收拆成「能跑、不硬编码、多类修改同时成立」。对做 agent 的人，提升空间可能不在模型本身，而在规格、回滚和可验证的中间产物。
