谷歌开源 Harness²：不动权重，让智能体自己改自己的“外壳”

谷歌开源了框架 Harness²（github.com/google-research/harness2，论文 arXiv 2610.14224），思路是不改模型参数，而是让智能体自己改写包在模型外面的那层“马具”——系统提示词、护栏、记忆、工具指导、子智能体、技能、脚本、插件共八个可编辑组件。它做双层递归：任务级用“提议–探测–组合”挑出对当前任务最有效的改法，元级把成功的改法和执行轨迹沉淀下来，指导下一个陌生任务。

看点权重改不动的时候（闭源 API、算力贵、还会灾难性遗忘），“改外壳”几乎是唯一还能落地的路径。更值得记的是数字：单步优化后 WorkBuddy-Bench +11.5、JobBench +4.5、LAB +11.8。模型没变、成绩变了——这对“模型能力”这个概念本身的冲击，比分数更大。

10/25 17:37 机器之心 ↗

谷歌开源 TorchTPU：TPU 成了 PyTorch 的原生设备

据机器之心报道，谷歌开源 TorchTPU，让 TPU 可以作为 PyTorch 的原生设备使用，报道称这意味着“CUDA 最深的护城河开始松动”。

看点这条的价值不在谷歌，在别人的机房。如果 TPU 能被 PyTorch 直接调度，“必须买 N 卡”这个前提就松了一格。今年算力叙事一直卡在供给上，这类降低迁移成本的动作，比再发一个模型更影响长期价格。

Anthropic 把 Claude 推进“后台常驻”：Duet 智能体研究预览上线

Claude Duet 定位是能在后台持续运行、主动识别用户需求并直接执行任务，而不是等你提问，面向工作任务繁重的专业人士与小企业主。目前仅通过候补名单向美国地区的 Claude Pro 与 Max 订阅用户开放。

看点这是 Claude 从“对话式助手”转向“常驻执行者”的第一步，也是最容易出事的一步。主动型智能体的难点从来不在能力上限，而在“什么时候不该动”——谁来决定它有没有越界，目前没有答案。

10/26 09:53 都市快报 ↗

Kimi 凌晨致歉：K3.1 Pro 限流、额度被白白烧掉，补一周用量

Kimi 官方 10/26 凌晨就“会员使用 K3.1 Pro 时出现限流及不必要的额度消耗”致歉，并宣布对有效期内的所有订阅会员重置一次：获得月度总额 25% 作为补偿，约等于一周用量；若当前用量不足月度总额 25%，则重置为 0。官方同时表示已调整配置，在减少不必要的子 Agent 调用与输出长度。

看点道歉信里最实在的一句是“减少不必要的子 Agent 调用”——这几乎点破了当下 Agent 产品的通病：能力靠堆调用堆出来，账单也靠堆调用堆出来。发模型只要一晚，把单位成本降下来要一个季度。

无问芯穹联手三体宇宙，发布“智子 Agent 1.0”

10/25 在三体日·脱水浸泡嘉年华上，AI 原生基础设施服务商无问芯穹与三体宇宙宣布战略合作，并发布首个合作成果——具有智子人格特征的 AI 对话 Agent“智子 Agent 1.0”。

看点这是一次“基础设施公司 + 科幻 IP”的组合：模型能力大家拉不开差距时，人格、世界观和角色资产成了差异化的一层皮。能不能从“会聊天的智子”长成“能干活的智子”，是这类 IP Agent 的共同考卷。

停训 11 天后重启：OpenAI 把最强模型的训练挪进断网环境
