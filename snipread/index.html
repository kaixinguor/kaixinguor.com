四件事，做到底

框选识字

在扫描页上拖一个框，即可识别框内文字。用的是 macOS 内置的文字识别，简体中文、繁体中文、英文都能认。 识别在你的 Mac 上完成，书页图片不会离开电脑。

批注

高亮、矩形框、画笔、文字批注、橡皮擦，像在纸书上做标记。自动保存，随时撤销。 可以导出带批注的 PDF，全部页、当前页或指定页码范围都行。

笔记

每本书一份笔记，和原文并排打开，支持 Markdown。

书架

文件夹分类，拖动整理。自动记住每本书读到哪一页、缩放多少，下次打开接着读。 触控板双指缩放，以手指位置为中心放大缩小。

和系统自带的比

macOS 的「预览」配合「实况文本」，也能在扫描页上选中文字。差别在于：它是一页一页手动框，而摘读是为读书这件事准备的。

预览 + 实况文本摘读
扫描页上识字能，但要手动选中、逐页来拖一个框，立刻出结果，一键复制
批注只有基础标记高亮、框、画笔、文字批注，可撤销可导出
读书笔记没有每本书一份，和原文并排
书架靠文件夹自己管分类、记住读到第几页

以 macOS 26 的「预览」为准。Apple 每年改系统，这些可能变。

常见问题

支持竖排古籍吗？

暂不支持竖排文字的识别。横排的影印本、教材、论文都没问题。

能整本书搜索吗？

暂时不能。现在的搜索是按书名，还没有做全文检索。

除了 PDF 还能读什么？

只有 PDF。图片、EPUB、Word 都还不支持。

我的书和笔记存在哪？

默认在 ~/Library/Application Support/com.mathster.SnipRead/， App Store 版在沙盒容器里。可以在「设置 → 数据」里更换位置，书和笔记会一起迁移。

换电脑怎么办？

把那个数据文件夹整个拷过去，再在设置里指过去就行。

还需要帮忙？

安装、权限、数据迁移的问题都在帮助与支持里，也可以直接写信。
